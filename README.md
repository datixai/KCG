# KCG — Kashmir Construction Group

Website built with Next.js 15 (App Router), React 19, TypeScript and Tailwind CSS v4.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Edit phone, WhatsApp, email and address in `src/config/site.ts`.

## Structure

- `src/app` — layout, page, global styles
- `src/components` — Header, Hero, Services, About, Projects, Contact, Footer, WhatsAppFloat
- `src/config/site.ts` — business details and navigation
- `public/brand` — logo
